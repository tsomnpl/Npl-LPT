## Post LinkedIn — Future-Tech React

Cette semaine, j'ai finalisé l'application **Future-Tech** en React avec une architecture propre, des composants réutilisables et une navigation fluide.

Le projet inclut :
- un routage complet avec **React Router** ;
- des pages dynamiques pour les projets et les articles ;
- des formulaires contrôlés avec validation ;
- un design moderne et responsive avec **Tailwind CSS**.

### Technologies utilisées
- React
- TypeScript
- Tailwind CSS
- React Router
- Vite

### Ce que j'ai appris
- structurer une application React maintenable ;
- créer des composants réutilisables ;
- gérer des données API avec `fetch`, `useEffect` et `useState` ;
- améliorer l'expérience utilisateur avec validation, états de chargement et gestion d'erreurs ;
- préparer un projet prêt au déploiement.

Merci à **Les Pros de la Tech** pour les challenges pratiques et la progression continue.

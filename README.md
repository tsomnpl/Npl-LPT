# Future-Tech

Site vitrine moderne réalisé pour présenter des services numériques et valider les challenges de Les Pros de la Tech.

## Description

Future-Tech est un site vitrine moderne développé dans le cadre des challenges de Les Pros de la Tech.

Le projet présente les compétences acquises en :

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Git
- GitHub

## Fonctionnalités

- Landing Page responsive
- Navigation responsive
- Hero Section
- Services
- FAQ interactive
- À propos
- Contact

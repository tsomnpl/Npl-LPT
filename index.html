Future-Tech

Projet de TCHIWANOU Isaac — Studio basé à Lomé, Togo

Future-Tech est un studio créatif digital spécialisé dans le design web, l'UI/UX, le développement numérique et les technologies innovantes. L'objectif est de concevoir un site complet incluant portfolio, blog et services professionnels.

Nous croyons que le futur appartient à ceux qui osent innover dès aujourd'hui.

Découvrez nos inspirations sur notre chaîne : YouTube

Fonctionnalités prévues

  • Création de sites web modernes (WordPress & Elementor Pro)
  • Design UI/UX (Conçu sur Figma)
  • Développement d'applications web
  • Solutions d'intelligence artificielle
    • Chatbots intelligents
    • Analyse de données
    • Automatisation des tâches
  • Portfolio filtrable, Blog et Page Tarifs
  • Page 404 personnalisée avec animations
  • Veille technologique via YouTube

Technologies et Design System

Outils utilisés : WordPress, Elementor Pro, Essential Addons.

  • Couleurs : Marine (#1E3A5F), Violet (#6366F1), Doré (#C9A84C)
  • Typographies : Space Grotesk pour les titres et Inter pour le corps.

Étapes de réalisation du projet

  1. Analyse des besoins et Maquettes Figma (12 colonnes)
  2. Création des maquettes UI/UX
  3. Développement du prototype sous WordPress
  4. Tests et optimisation
  5. Déploiement du projet fil rouge
